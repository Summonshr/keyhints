KeyHints

Everything here works with Tab, Shift+Tab, Enter and Space.

Shortcuts

Sites where single keys are off

There, f, F, ; and y f are left to the site (YouTube: f fullscreen; Gmail: f forward). Alt+J always works. The toolbar button switches the site you're on.


    Hint letters


    Lowercase letters, no repeats, at least 4. These are for generated labels; labels taken from an element's name use any letter. Saved labels using a letter you remove are forgotten; the rest are kept.

    Hint style

    Saved labels

    Elements you pick keep their label on later visits. Forget them per site or all at once.

    Your keys so far

    No picks yet.

    Counted from your saved labels, in this browser only. Nothing is sent anywhere.

    Share and back up

    "Copy keymap" (under each site above) copies that site's labels as text a friend can paste here. A backup file holds every site's labels and your settings, for a new computer.



    Imported labels are added to yours; where two clash, the pinned one, then the most recent, wins.

    Sync

    Settings and pinned keys go to your other computers when the browser's sync is on. Learned labels stay on each computer. Forgetting a site's labels unpins its keys on every computer too.

    Palette search

    The palette (Alt+K) always searches open tabs and the page. It can search bookmarks and history too, if you allow it. Nothing leaves your browser either way.

    Show keys

    For screen sharing and recordings, so others can follow. What you type into fields is never shown.

    Tips

    A short note the first time something is useful (a video plays, you open X…). Each shows once.
